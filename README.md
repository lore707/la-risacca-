# La Risacca

Repository del progetto MVP La Risacca.

Il repository è inizializzato con Git per conservare la cronologia delle modifiche. Il collegamento a GitHub verrà configurato successivamente.

## File iniziali

- `.gitignore`: esclude dipendenze, file generati e configurazioni locali con credenziali.
- `README.md`: descrizione del progetto; verrà aggiornato con le istruzioni di installazione e avvio durante lo sviluppo.

Le credenziali reali devono essere conservate in un file `.env` locale. Un eventuale `.env.example` deve contenere solo valori di esempio, senza segreti.
